# TCS 콘텐츠 관리

관리자 화면은 개발 버전의 `/admin/`에서 열립니다. Sanity에 초대받은 계정으로 로그인합니다. 운영 사이트는 별도 전환 전까지 기존 버전을 유지합니다.

## 고객이 수정할 수 있는 항목

- 페이지 문구·대표사진: 페이지를 선택하고 한국어·English를 각각 수정합니다. 메인 대표 이미지를 비워두면 현재 개념도를 유지합니다.
- 제작사례: 제품명, 분야, 설명과 사진을 추가합니다. 첫 번째 사진이 대표사진이며 사진을 끌어서 순서를 바꿉니다. 실제 사진은 프레임 채우기, 투명 CAD 이미지는 전체 보이기를 선택합니다. 사진 회전과 초점 위치도 조정할 수 있습니다.
- 주요 고객사: 회사명, 로고, 홈페이지 또는 Google 지도 주소를 수정합니다.
- 보유 장비: 장비명·규격·제조사·수량과 소프트웨어 목록을 수정합니다.
- 회사정보·연락처: 주소·지도·전화·이메일·문의 안내를 수정합니다.

## 검토와 발행

문서를 선택한 뒤 **미리보기** 탭에서 저장 중인 초안을 확인합니다. 아직 발행하지 않은 내용은 이 화면에만 표시됩니다. 한국어·영어 버튼으로 두 언어를 확인할 수 있습니다.

**발행**을 누르면 개발 버전 재배포가 시작됩니다. 적용까지 빌드 시간이 걸립니다. 초안 저장만으로는 공개 화면이 바뀌지 않습니다. 운영 사이트 반영은 현재 연결하지 않습니다.

배경 제거는 CMS의 기본 자동 기능이 아닙니다. 처리된 PNG·WebP를 업로드하세요. 업로드한 이미지는 Sanity에 저장하며 웹사이트는 표시 크기에 맞춘 이미지를 사용합니다.
